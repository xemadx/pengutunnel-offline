اصلاح DNS در هستهٔ v5.1.3، رفع باگ‌های نصاب و نصب پایدار CLI.

- مقصد نادرست `0.0.0.0` در ارسال گروهی DNS با همسان‌کردن خانوادهٔ سوکت و فرستنده اصلاح شد؛ DNS این build صریحاً IPv4 است.
- هش بسته، پورت‌ها، تولید TOML، تعارض health port، جایگزینی سرویس فعال و EOF بررسی می‌شوند.
- نصاب خوانا است؛ فایل‌ها را بعد از نصب حفظ می‌کند و فرمان `sudo pengu` برای بازکردن منو دارد.
- `sudo pengu update [TAG]` انتشار مشخص را روی هر دو سمت نصب می‌کند؛ updater پس‌زمینهٔ upstream فعال نمی‌شود.
- هسته باینری اصلاح‌شدهٔ مشخص است، نه سورس اصلی بازیابی‌شده یا هستهٔ کاملاً متن‌باز. سورس ابزارهای جدید و آزمون‌ها موجود است.

نصب روی هر دو سرور:

```bash
curl -fsSL https://raw.githubusercontent.com/emad1381/pengutunnel-offline/main/install.sh | sudo bash
```

نتیجهٔ آزمون، نسخه و محدودیت‌ها را در README و `docs/AUDIT-R3.fa.md` بخوانید. تست ایزولهٔ محلی تضمین رفتار تمام مسیرهای اینترنتی نیست.
